# 渐变背景生成器

这是一个使用 Next.js 的 React 项目，用于生成随机渐变背景，具有色彩选择、高度调整、预设色彩方案选择等丰富的功能。

## 功能特性

### 🎨 色轮色彩选择
- 全新设计的交互式色轮，支持同时选择两种颜色
- 拖拽式操作，直观易用
- 双颜色标记点，清晰显示当前选择

### 🤖 智能配色算法
- **自由选择模式**：用户可以完全自由地选择两种颜色
- **推荐选择模式**：基于色相轮的和谐配色算法，自动推荐最佳配色方案
- 支持的配色算法：
  - **互补色**：色相相差 180° 的颜色，对比强烈
  - **邻近色**：色相相差 30° 的颜色，和谐统一
  - **三角色**：色相相差 120° 的颜色，均衡协调
  - **分裂互补色**：互补色两侧的颜色，对比柔和

### 📐 丰富的渐变选项
- 渐变角度调整（0° - 360°）
- 预览高度自定义（100px - 800px）
- 一键复制 CSS 代码
- 6 种精美预设方案

### 🎲 随机生成
- 一键生成随机渐变
- 推荐模式下自动生成和谐配色

## 色彩推荐算法说明

本项目采用了基于色相轮（HSL 色彩空间）的经典配色理论：

### 1. 互补色 (Complementary)
- 色相相差 180°
- 特点：对比强烈，视觉冲击力强
- 适用于需要突出重点的场景

### 2. 邻近色 (Analogous)
- 色相相差 ±30°
- 特点：和谐统一，过渡自然
- 适用于需要舒适视觉体验的场景

### 3. 三角色 (Triadic)
- 色相相差 ±120°
- 特点：均衡协调，色彩丰富
- 适用于需要多种色彩的场景

### 4. 分裂互补色 (Split Complementary)
- 互补色两侧各 30°
- 特点：对比柔和，比互补色更和谐
- 适用于需要对比但不刺眼的场景

## 使用说明

### 自由选择模式
1. 点击或拖拽色轮上的标记点选择颜色
2. 两个颜色可以完全独立选择
3. 点击下方的颜色方块切换当前活动颜色

### 推荐选择模式
1. 选择一个基础颜色
2. 系统自动推荐互补色作为第二个颜色
3. 下方会显示 7 种推荐配色方案
4. 点击推荐颜色可直接应用

### 其他功能
- **随机生成**：点击按钮生成随机配色
- **预设方案**：快速应用 6 种精选配色
- **角度调整**：拖动滑块改变渐变方向
- **高度调整**：自定义预览区域高度
- **复制代码**：一键复制生成的 CSS 代码
